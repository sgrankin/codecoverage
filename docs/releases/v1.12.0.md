## Sparkline and delta in push-run job summaries

- Baseline-storing runs (pushes to `main_branch`) now render the coverage sparkline and the
  delta against the previous stored baseline in the job's step summary. Previously the summary
  on push runs showed bare coverage — the trend appeared only on pull requests.
- The delta is computed even with `sparkline_count: 0`, and the `coverage_delta` /
  `baseline_percentage` outputs are now set on push runs too (given a prior baseline exists).
- First run on a branch (no prior notes) still reports absolute coverage only.

**Full Changelog**: https://github.com/sgrankin/codecoverage/compare/v1.11.0...v1.12.0
