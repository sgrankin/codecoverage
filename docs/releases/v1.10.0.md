## Go coverage: statement coverage as the primary metric

- Go coverage profiles now report **statement coverage** (matching `go tool cover -func`) as the primary metric.
- New `statement_percentage` output — set for Go coverage, empty for other formats. `coverage_percentage` remains line coverage and is always set.
- `coverage_delta` and `baseline_percentage` now track the primary metric (statement coverage for Go, line coverage otherwise).
- Report counts use the primary unit throughout, with a clarifying footnote for Go.

## Multiple coverage comments per PR

- New `comment_id` input namespaces the PR comment marker, so jobs with different ids (e.g. one per coverage format) maintain separate comments on the same PR. Re-runs with the same id update in place.

## CI and maintenance

- New `dogfood-go` CI job exercises the Go format end to end against a sample module.
- Dependabot update cooldowns (7 days, 14 for npm majors) and npm `min-release-age`.
- Updated GitHub Actions: `actions/checkout` v7, `actions/setup-go` v6.
- New `Release` workflow for cutting releases via workflow dispatch or a `release/<version>` branch push.
