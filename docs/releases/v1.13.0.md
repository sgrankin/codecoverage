## Package table: size-scaled coverage bars + hotspot strip

- Each row of the "Coverage by Package" table now carries a stacked coverage bar scaled
  like a 1-D treemap: bar length is proportional to the package's statement count
  (largest package = 24 chars), solid = covered, light = uncovered. Large coverage holes
  read as long light runs, directly comparable down the column; nonzero segments never
  round away, so a one-statement hole stays visible.
- A one-line "**Most uncovered:**" strip above the table names the top five packages by
  uncovered statements (omitted when everything is covered).
- Counts remain in the report's primary unit (statements for Go, lines otherwise).
